Built on Enterprise Zero-Trust Security Architecture

Patient health information demands strict data isolation. RxNXT enforces Zero-Trust principles across every layer of the application so your clinic data is 100% protected.

PostgreSQL Row-Level Security (RLS)
Data isolation is enforced at the database kernel level. Doctor A cannot read Doctor B's records, even if raw SQL queries are attempted.
Encrypted JWT Session Auth (No Parameter Tampering)
The frontend never sends plain `clinic_id` parameters. Identities are verified via encrypted server-side JWT session cookies.
HIPAA-Ready Compliance Audit Logs
Database triggers automatically record `INSERT`, `UPDATE`, and `DELETE` events for complete audit compliance.
Zero-Trust Execution Flow
1. Doctor Browser Encrypted JWT Cookie
↓ API Gateway Verification
2. Next.js Serverless Edge Session Verified
↓ PostgreSQL Row-Level Query
3. Supabase Postgres RLS Strict Tenant Match
🔒 Zero risk of cross-tenant data leaks or unauthorized record access.

Frequently Asked Questions

Everything you need to know about setting up RxNXT in your clinic.

How fast can our clinic start using RxNXT? ▼

You can start using RxNXT in under 5 minutes. Since it is cloud-native and serverless, there is no software installation required. You simply log in via any desktop browser or tablet.

Can we upload our clinic's specific medicine brand list? ▼

Yes! RxNXT includes a Bulk CSV Import module. You can upload your preferred brand catalog, and the search engine will prioritize your clinic's favorite medicines at the very top of search results.

How does the WhatsApp PDF sending feature work? ▼

When a doctor completes a prescription, a single click dispatches a formatted PDF copy directly to the patient's registered mobile number via WhatsApp, ensuring instant access without physical paper clutter.

Is our patient data safe and isolated from other clinics? ▼

Yes. RxNXT is built on a Zero-Trust security model using PostgreSQL Row-Level Security (RLS). Every query is cryptographically checked to ensure that your clinic's data is strictly isolated and inaccessible to any outside party.
